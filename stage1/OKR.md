# Stage 1 — Proof of Concept

更新日期：2026-10-21

状态：PLANNED

## 阶段目标

用小数据集验证：地震动与少量建筑属性能否通过联合训练的编码器和楼层查询解码器，预测不同层数建筑的逐层响应。先看能不能学会，通过后再扩大数据和模型。

## 实验范围

- 输入：地震动、层数、总高度、结构类型、设防水平、基本周期 T1。
- 输出：每层相对位移、绝对加速度时程；由相邻层位移计算层间位移角、PIDR 和参考损伤等级。
- 结构：先限于新 MDOF 已验证的剪切型结构。设防水平必须有明确参数生成依据；没有依据时固定，不随机编造标签。
- 采样：第一轮统一 50 Hz；记录不足时补零并使用有效时间掩码，不截掉强震段。保留用于衰减的尾段，但本阶段不评估残余漂移。
- 两模块联合训练；latent 保留时间信息，不要求预训练或模态标签。
- 本阶段不做完整 P-58 损失评估、FNO 融合、变采样率、模态解释或大规模结构外推。

### 初始验收门槛

以下为本阶段预设的工程试验门槛，不是规范限值。开始训练前冻结定义；若修改，保留修改原因和历史版本，不用测试结果反向调整门槛。

1. **能拟合：**24 个训练算例中，位移和加速度的逐算例相对 L2 误差中位数均不超过 10%。
2. **能初步泛化：**预留 test 的位移和加速度 MSE 分别相对各自简单基线下降至少 30%；PIDR 和 PFA 的逐层相对误差中位数分别不超过 20%。
3. **结果稳定：**三个 seed 均检查上述独立测试指标；同时报告 P90、最差算例和严重低估，不能只报告总体均值。

指标约定：

- 时程相对 L2 按算例在全部有效楼层/时间上计算；近零响应采用仅由训练集确定的分母下限，并报告下限。
- PIDR/PFA 相对误差使用预先固定的近零保护规则，同时报告原单位绝对误差与有符号偏差。
- 加速度基线按统一坐标约定构造，不能混用旧求解器与常见公式的符号。
- 以上指标证明的是小规模可学习性；通过不代表真实建筑验证、结构外推或 P-58 全流程验证已完成。

代码入口计划：`scripts/train.py`、`scripts/evaluate.py`；配置计划：`configs/train.yaml`。

## 执行顺序与阶段决策

`O1 数据合格 → O2 前向/反向通过 → O3 小样本拟合 → 小数据训练与独立测试 → POC 结论`

- **PASS：**拟合与独立测试门槛通过，三个 seed 均复核；进入下一阶段扩大数据与结构覆盖。
- **PARTIAL：**能拟合但独立测试不达标，或结果不稳定；先改输入、数据覆盖或模型，不直接扩大算例数量。
- **FAIL：**小样本也无法拟合；定位实现、归一化、latent 容量和优化问题。
- 必要诊断：可用“真实逐层响应 → 辅助编码器 → latent → 查询解码器”检验重建能力；只作为诊断，不能计为端到端预测成果。
