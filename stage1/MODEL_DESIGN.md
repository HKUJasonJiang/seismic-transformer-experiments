# Stage 1 模型设计

状态：patch=60 已在 5090 通过核验和真实训练。24 个单波算例拟合通过；十波 3/5/8 层试验未达到泛化门槛。当前使用原训练分区的 65 个 DS_ref>2 算例排查 A/B 拟合，见 [DIAGNOSIS_PLAN.md](DIAGNOSIS_PLAN.md)。下文描述保留的基线结构。

## 输入和输出

| 项目 | 内容 | 张量形状 |
| --- | --- | --- |
| 地震动 | 50 Hz、SI 加速度，含有效自由衰减尾段 | `[B,T,1]` |
| 数值属性 | 层数 N、总高度 H、设防水平、初始周期 T1 | `[B,4]` |
| 类别属性 | 结构类型编码，不使用建筑 ID | `[B]` |
| 楼层查询 | 1 到 N；0 表示补齐位置 | `[B,F]` |
| 位移输出 | 每层相对地面位移，m | `[B,T,F]` |
| 加速度输出 | 每层绝对加速度，m/s² | `[B,T,F]` |

T 为保存网格的有效时程长度（含尾振）；F 为 batch 内补齐后的查询楼层数。
当前十波数据覆盖同类 3/5/8 层模型，各有三个初始周期配置；其他结构类别和未见层数的预测能力尚未验证。

## 模型 A：条件时序编码器

1. 地震动每 60 点组成一个 patch（50 Hz 时对应 1.2 s），从 60 维线性投影到 128 维。
2. 加入以秒为坐标的正弦/余弦位置编码和 patch 有效比例，屏蔽无效补零。
3. 四项数值属性用固定工程尺度缩放后经 MLP 编码，结构类型使用类别 embedding。
4. 4 层 Transformer，4 个注意力头，FFN 宽度 512。建筑条件在每层通过 FiLM 调整特征。
5. 输出完整动态 latent 序列 Z；同时保留建筑条件表示 z_s。

3000 点对应 50 个 patch；3751 点补齐至 3780 点，对应 `Z=[B,63,128]`。
latent 是可学习的动态特征；目前不赋予真实振型、模态坐标等物理名称。

## 模型 B：共享楼层查询解码器

1. 查询特征为楼层相对位置 i/N、楼层序号 i/20、是否顶层，再结合 z_s 编码。
2. 每层 query 对 Z 做 cross-attention，取得该层的响应上下文。
3. 该层上下文与每一个时间 token 融合，保留全时程信息。
4. 两个共享输出头分别生成每个 patch 的 60 点位移和 60 点加速度，拼接还原完整时程。

同一组参数处理所有楼层，可以查询单层、若干层或全部楼层。楼层查询顺序不改变对应楼层的输出。
不同建筑的楼层和时间均有 mask；无效位置输出为 0，不参与损失。
初版使用等层高模型，i/N 同时代表相对高度；逐层不等高需扩充查询特征，不能直接视为已支持。
时间输出仍与输入使用同一 50 Hz 网格；变采样率不在当前实现范围内。

```mermaid
flowchart LR
    G[地震动] --> P[时间 patch 编码]
    S[建筑属性] --> C[结构条件编码]
    C --> E[FiLM Transformer]
    P --> E
    E --> Z[动态 latent Z]
    Q[楼层查询] --> D[共享查询解码器]
    C --> D
    Z --> D
    D --> U[每层位移]
    D --> A[每层绝对加速度]
    U --> R[漂移与参考损伤等级]
    A --> F[逐层 PFA]
```

## 联合训练和派生指标

两个模块一次前向、一次反向共同更新，不需要 latent 标签或先预训练其中一个模块。
顶层响应直接从全楼输出取顶层，不把预测顶层曲线串接到第二阶段。

初始损失：

`L = MSE(u / scale_u) + MSE(a / scale_a) + MSE(theta / scale_theta)`

每个 MSE 先按每栋建筑的有效时间/楼层求均值，再对建筑求均值。漂移由相邻层位移差除以实际层高计算，全层监督要求按 1..N 排序。
三个尺度使用训练分区的 RMS，保存来源和数值；不移除响应均值，不使用验证/测试标签拟合尺度。
O3 尺度只从各轮指定训练分区拟合，来源和数值随权重记录。

输出再计算每层 PIDR/PFA、全楼最大值、危险层、逐层/全楼 DS_ref，以及顶层两条曲线。
DS_ref 使用显式漂移阈值，不设独立分类头。查询局部楼层时，不计算全楼指标或缺失相邻层的漂移。
峰值先在模型的保存网格上计算；与 MDOF 全积分网格峰值的差异另行评估。

## 本轮取舍

- 使用最小 FiLM Transformer 基线，暂不增加 FNO/FFT 分支、模态标签或额外全局指标预测头。
- patch 化将时间 token 数减少约 60 倍；latent 仍保留完整时间次序，片内信息由 60→128 投影编码。
- 当前 dropout=0；patch=60 在服务器核验为 1,116,792 个参数。历史 patch=10 版为 1,097,492 个参数。
- 完整地震动编码不是在线因果预测；先研究给定完整波形的快速全楼响应。

## 小样本拟合的损失诊断

首轮使用上述全训练集 RMS 尺度。低 PGA、小位移算例的相对误差较大，因此另外建立 `poc_balanced.json` 实验：每个通道的逐算例 MSE 除以该训练算例真值的均方，再对算例等权平均。分母下限为全训练集 RMS 的 1% 的平方，避免近零响应权重无界。

这些尺度只用于训练损失；模型输入与输出的物理单位不变，推理时不需要响应真值。原始损失和精调结果保留，各实验使用独立 run ID。

## 非线性诊断后保留的拟合模型

`basis_joint` 保留上述 A、patch=60 和 128 维 latent。B 改为预测八组随时间变化的位移/加速度系数，再用楼层坐标的完备离散正弦基组合出查询层响应，代码在 `src/basis_decoder.py`。当前实现明确要求 N≤8；3/5/8 层分别使用前 N 个基，基由 N 和查询层 i 确定，不是真实振型标签，也不是时间频域 FNO。

该版本已经在原 65 个非线性训练样本上通过每类层数的拟合门槛。与原 B、冻结 A、固定输出头、近等参数量的加宽 B 比较，见 `DIAGNOSIS_PLAN.md` 和私有诊断报告。不同输出表示的参数量与优化难度不同，结论限于当前数据和计算预算。

`scripts/export_nonlinear.py` 导出不含优化器或逐算例 latent 表的 `inference.pt`；`src/nonlinear_inference.py` 的 `load_query_model` 读取后仍使用原 `SeismicQueryModel.forward` 输入契约。推理仅需地震动、建筑属性、类型、楼层查询及时间 mask，不需要真实屋顶曲线或响应标签。该推理核验和全部训练层的独立查询已在 5090 通过。
