## 0. 总览

### 0.1 要做什么

训练一个神经网络，代替剪切型多自由度结构的非线性时程分析，并且做到在**没见过的地震动**和**没见过的结构**上也能用。

以前的论文投稿多次被评"泛化性不足"。exp5 的结果说明了两个原因：

- 训练只有 7 条地震动，新地震动上的峰值普遍只预测到真实值的一半左右；
- 结构几乎没有变化。

exp7 同时处理这两点：

- **改进模型**：重点改解码器和输出方式；
- **重新生成一套大数据集**：地震动多，结构多样，并事先留出没见过的层数和周期。

### 0.2 模型的输入和输出：只用实际能拿到的信息

| 输入 | 说明 | 实际应用中从哪来 |
|---|---|---|
| 地面加速度时程 | m/s²，50 Hz，固定 66 秒（3,300 点） | 地震记录或情景地震动 |
| 层数 N | 整数 | 建筑信息 |
| 基本周期 T1 | 秒 | 可以用传感器实测（例如环境振动测试），也可以按规范公式估计 |
| 设防等级 | 6、7、8、9 中的一个，作为类别输入 | 建筑信息或建造年代 |
| 结构类型 | 本版只有"框架"（编号 0） | 建筑信息 |

- **不输入**刚度、质量、屈服强度。实际应用中拿不到这些量。
- 生成数据时，靠改变刚度来造出不同的 T1，但模型只看到 T1，看不到刚度本身。
- 总高度不作为输入，因为层高固定为 3 m，它与层数是重复信息。

**输出**：每一层的相对位移时程（m）和绝对加速度时程（m/s²），都是 50 Hz。层间位移角、楼层峰值加速度、损伤等级都由输出推算，模型没有单独的分类头。

### 0.3 模型结构要点

整体分两部分：编码器"A"和楼层查询解码器"B"。完整数据流见第 4 节。

1. **编码器 A 不改**，与 exp5 相同：
   - 地震动每 60 点（1.2 秒）切一段，线性映射后加上时间位置编码，做 LayerNorm，再经过若干层 Transformer。
   - 每层 Transformer 之前，用结构条件向量做缩放和平移（FiLM 调制）。
   - 输入端的 LayerNorm 要保留：以前的实验发现，去掉它会让模型在新地震动上明显变差。
2. **解码器 B 改为交叉注意力**：
   - 每个"一层楼 × 一个时间段"是一个查询，可以读取编码器输出的全部时间段。
   - 查询之间互不读取。这参考了 CVPR 2026 最佳论文 D4RT（逐点查询的四维重建模型）。
3. **输出相对加速度**：网络预测相对加速度，再加上地面加速度得到绝对加速度。高频成分大多来自地面运动，不需要网络重新学。
4. **查询带局部地震动片段**：每个查询附上本段 60 点和前后各 30 点的地面加速度，补回编码器压缩掉的细节。这也是参考 D4RT（它在查询中附带局部像素小块）。
5. **地震动强度如何传入（幅值分解）**：LayerNorm 会抹掉幅值，所以强度要单独送进去。具体有两条通路：
   - 编码器看到的是"地面加速度 ÷ 该记录的 PGA"，也就是只有波形形状；
   - **log(PGA/g) 作为一个数值，并入结构条件向量**。它通过 FiLM 调制编码器的每一层，同时加到解码器的每个查询上；
   - 网络输出无量纲的响应，最后**再乘以 PGA**，还原物理单位。

   这样，在线性范围内，响应与强度成正比这一关系是内置在结构里的；非线性程度则由 log(PGA) 条件来调节。PGA 是从输入记录本身算出来的，实际应用时也能得到。
6. **固定 50 Hz**，本版不做分辨率无关设计。
7. **两套规模**：
   - 小型（约 150 万参数），用于在 exp5 数据上对比；
   - 基础型（约 900 万参数），用于新数据集。

   参数量是估算，以运行时打印为准。

上面第 2–5 项都可以单独开关，所以能逐项检验各自的作用。

| 时长 | 66 秒，共 3,300 点：60 秒地震动加 6 秒零输入，用来保留残余变形；正好切成 55 段 |
| 结构类型 | 只用框架（类型 0）。框剪结构以后再做 |
| 训练层数 | 2、3、5、6、8、9、10 |
| 留出层数 | 内插：4、7；外推：11、12、13、14 |
| 设防等级 | 6、7、8、9 都参加训练，不留出 |
| 如何造出不同的 T1 | 由参数生成程序按"层数、设防等级、类型"给出基础参数，再把所有楼层的**刚度乘以刚度系数**，**屈服力乘以同一个系数**。这样屈服位移角保持不变，T1 约变为原来的 1/√刚度系数 倍 |
| 刚度系数（训练） | 0.6–1.6 之间对数均匀抽样，但剔除 1.15–1.30 这一段（这一段留作 T1 内插测试） |
| 刚度系数（外推测试） | 0.45 和 2.1，对应 T1 约为原来的 1.49 倍和 0.69 倍 |
| 强度为什么跟刚度一起缩放 | 实际应用中测不到强度。如果让强度独立变化而又不告诉模型，同一组输入会对应不同的答案；如果把强度作为输入，实际使用时又拿不到。所以本版让强度跟刚度一起缩放（同一类结构的屈服位移角大致稳定），让"层数、T1、设防等级"足以确定结构。强度的离散性以后单独研究 |
| 组合方式 | 不做"记录 × 结构"全组合。每条训练记录配 **16 个随机结构**：每次随机抽一组（训练层数之一、设防等级之一、刚度系数），各算一个随机强度，共约 4.1 万个训练算例 |
| 强度抽样 | 每个算例按 Sa(T1)（周期 T1、5% 阻尼的谱加速度）在对数尺度上均匀抽样。区间在预检中标定，使损伤等级分布约为：0–1 级 40%，2 级 30%，3 级及以上 30%。Sa(T1) 只用来决定缩放倍数，不作为模型输入 |
| 为相对加速度做的处理 | 地面加速度与结构响应走**同一条**从积分网格到 50 Hz 的降采样滤波路径。这样"绝对加速度 + 地面加速度 = 相对加速度"在 50 Hz 上严格成立 |
| 时间对齐 | 模拟器的旧版材料兼容模式只允许 legacy 对齐（physical 会被拒绝）。legacy 下位移第 i 行存的是 u(t_{i+1})，生成时下移一行，与 stage1 相同，使位移和加速度都落在 t_i 上 |
| 规模 | 全部约 5.8 万个算例，约 12 GB（预估）。每 1,000 个算例存成一个分片 |

### 0.5 实验安排

**第一阶段：在 exp5 的旧数据上做逐项对照**

- 数据：exp5 的数据和划分，7 条训练地震动。
- 小型规模，五个变体逐步增加改动，每个 3 个随机种子，共 15 次运行。
- 目的：确认新代码能复现 exp5，并看每项改动是否有帮助。
- 按开发集选出一个变体带入第二阶段。

**第二阶段：在新数据集上**（数据生成后做）

1. **主模型**：基础规模，用第一阶段选出的变体，全部训练记录，3 个种子。
2. **训练记录数缩放曲线**：训练记录取 7、30、100、300、1000、全部，变体用 `exp5_decoder` 和选出的变体，各 3 个种子。用来回答"exp5 在新地震动上失败，是否主要因为记录太少"。
3. **结构泛化测试**：层数内插、层数外推、T1 内插、T1 外推，分别在"地震动见过"和"地震动没见过"两种情况下测。
4. **跨数据库测试**：PEER 记录。
5. **基线**：零响应、线性弹性结构、最近邻查表。

### 0.6 事先规定的判断规则

- **第一阶段选变体**：在各种子都跑完的变体中，选开发集目标（各种子平均）最低的那个。不看测试集。
- **第二阶段的缩放曲线**：在"全部训练记录"这一档，若以下两条在 3 个种子上都成立，就认为"新地震动上的问题主要是数据量问题"：
  1. 未见记录测试的全楼位移 MSE 和全楼加速度 MSE，都不超过"已见记录、新结构新强度"参照组的 1.5 倍；
  2. 未见记录测试中，损伤等级大于 2 的算例，其"最大层间位移角 预测/真值"中位数落在 0.85 到 1.15 之间。
- **结构泛化**：只做描述性报告，不设通过门槛。重点看误差随外推距离如何变化。

1. 在 H200 上跑第一阶段 `full` 变体的第一个种子，确认自检通过 → **有问题就停下修正**

### 0.8 本版不做

- 框剪、砌体等非框架类型；
- 强度独立变化，以及把强度作为输入；
- 阻尼、层高作为变量；
- 分辨率无关设计；
- 多方向地震输入；
- 概率输出；
- 测试没见过的设防等级（类别向量无法泛化到没训练过的类别）。

## 1. 背景

- exp5（`exp/exp5-normalized-floor-query/`）的模型：编码器是 4 层 Transformer；解码器 B 只是全连接网络，第 k 段的输出只看第 k 段的时间向量。
  - 训练用 7 条 PEER 记录，3/5/8 层，周期比例 0.8 和 1.2。
  - 在没见过的地震动（peer_9、peer_10）上，最大层间位移角"预测/真值"的中位数只有 0.51；损伤等级大于 2 的 13 个算例中，12 个被低估。
  - 开发集误差从约第 800 步起就不再下降，说明模型只是记住了训练数据。
- stage1 的隔离诊断（`stage1/ISOLATION_RESULT.md`）：给 B 一个用真值优化出的理想时间向量，位移重建误差为 2–3%，全楼加速度仍有 16–18%。这说明 B 读加速度本身就有困难。
- 2026 年 8 月的旧模型实验（`6-Experiments/01L/results/formal_ood_closeout/formal_ood_closeout_report.md`，在论文目录中，不在本仓库）：
  - 用 3,474 条 KNET 基础波训练时，没见过的地震动上误差只比见过的高约 5%；
  - 结构内插时误差约为 2.8 倍。

  这说明地震动泛化主要靠数据量，而结构泛化才是短板。

## 2. 术语

| 术语 | 含义 |
|---|---|
| 基础地震动 / 基础波 | 一条原始加速度记录。它的所有缩放版本都算同一条基础波 |
| PGA | 地面峰值加速度。模型内部用 m/s²，报告时用 g（9.80665 m/s²） |
| T1 | 结构初始状态的基本周期，由质量和初始刚度做特征值分析得到 |
| Sa(T1) | 地震动在周期 T1、5% 阻尼下的谱加速度 |
| 刚度系数 | 所有楼层的初始刚度和屈服力同时乘以的系数（本版二者用同一个系数） |
| 层间位移角 | 相邻两层位移差除以层高 |
| 损伤等级 | 按最大层间位移角的阈值 0.5%、0.8%、2%、5% 分成 0–4 级（严格大于阈值才进入下一级）。这是本项目的参考分级 |
| 材料失效算例 | 模拟器报告材料失效，或层间位移角超过 5%。不作为真值，只记录数量 |
| 近重复记录 | 两条基础波各自去均值、归一化后，内积的绝对值大于 0.995 |
| 开发集 | 只用来挑选权重或变体，不用于最终结论 |
| 测试集 | 模型固定后才评估，每个最终模型只评估一次，并记录访问次数 |
| MSE | 物理单位的均方误差：位移 m²，加速度 (m/s²)²。每个算例先在有效时间和有效楼层上平均，再对算例等权平均；补齐部分不计入；位移和加速度不合成一个数 |
| 变体 | 模型的一种开关组合，在 `configs/run.json` 的 `variants` 中定义 |

## 4. 模型细节

代码在 `codes/model.py`。符号说明：B 是批大小，T 是采样点数，P 是时间段数（P = T/60 向上取整），F 是查询楼层数，d 是向量维度。

### 4.1 地震动预处理

1. 输入地面加速度 [B, T, 1]，单位 m/s²；时间掩码以外的样本清零。
2. **开启幅值分解时**：PGA = 有效部分的最大绝对值；信号 = 地面加速度 / PGA；条件量 = log(PGA / 9.80665)。
   **关闭时**：信号 = 地面加速度 / 9.80665，与 exp5 相同。

### 4.2 结构条件向量

- 数值输入由配置中的 `structure_features` 决定，目前是 [层数/10, T1/1 秒]。代码支持 `linear` 和 `log` 两种变换。
- 开启幅值分解时，在数值输入后追加 log(PGA/g)。
- 数值部分经过 全连接→64→64；结构类型、设防等级各用 32 维类别向量。三者拼接后经过 全连接→d→d 和 LayerNorm，得到条件向量 [B, d]。
- 模型记录训练中出现过的结构类型和设防等级。推理时遇到没训练过的类别，直接报错。

### 4.3 编码器 A（与 exp5 相同）

1. 信号每 60 点切一段，不足补零，得到 [B, P, 60]。
2. 线性层映射到 d 维，加上"有效采样比例"项和时间位置编码（以秒为单位，64 个频率，0.01–5 Hz），做 LayerNorm。
3. 条件向量经过全连接网络，得到每层的 γ 和 β。每层 Transformer 之前执行 x ← x·(1+tanh γ) + β。
4. 经过若干层 Transformer（先归一化、GELU、补齐段被屏蔽），再做 LayerNorm，输出时间向量 [B, P, d]。

### 4.4 解码器 B（交叉注意力版本）

一个查询对应"一层楼 × 一个时间段"，由四部分相加：

| 组成 | 计算 | 形状 |
|---|---|---|
| 楼层位置 | ξ = 楼层号 / 层数；取 [ξ, sin(π·2ᵏξ), cos(π·2ᵏξ)]，k = 0…5；经过 全连接→d→d | [B, F, d] |
| 时间段时刻 | 该段的时间位置编码，经过线性层 | [P, d] |
| 局部地震动片段 | 第 k 段的 60 点加前后各 30 点，共 120 个信号值，经过线性层；不做 LayerNorm | [B, P, d] |
| 结构条件 | 条件向量经过线性层 | [B, d] |

- 相加后展平为 [B, F·P, d]。
- 被读取的一方是编码器输出加上时间位置编码的线性映射。
- 每层：先归一化 → 交叉注意力读取全部有效时间段 → 前馈网络，两步都有残差连接。查询之间不做自注意力。
- 最后 LayerNorm 加线性层，每个查询输出 120 个数：前 60 个是位移，后 60 个是加速度。

### 4.5 输出组装

1. 各段的 60 点按顺序接起来，截到 T 点，得到 [B, T, F]。
2. 乘以训练集拟合的固定尺度；开启幅值分解时，再乘以 PGA。
3. **开启"输出相对加速度"时**：绝对加速度 = 输出 + 符号 × 地面加速度。模拟器保存的是"绝对 = 相对 − 地面"（`mdof-workbench/cpp/include/mdof/api.h`），所以符号取 −1。训练前代码会用数据核对：按该符号算出的相对加速度，其 RMS 必须小于取反符号时的结果，否则报错。
4. 补齐的时间和楼层置零。返回位移、绝对加速度、相对加速度三项。

### 4.6 exp5 风格的解码器（对照用）

当 `decoder_type = "concat"` 时：楼层位置经过 1→32→32，与该段时间向量拼接，再经过 160→256→256→120。开启局部片段时，片段嵌入加到 32 维楼层向量上。

### 4.7 两套规模

| 规模 | d | 注意力头 | 编码器层 | 解码器层 | dropout | 参数量（估算） |
|---|---:|---:|---:|---:|---:|---|
| `small` | 128 | 4 | 4 | 2 | 0 | 约 150 万 |
| `base` | 256 | 8 | 6 | 4 | 0.05 | 约 900 万 |

### 4.8 损失和训练

- 损失：位移、绝对加速度、层间位移角三项 MSE，每项除以该算例真实响应的均方值，权重都是 1。实现沿用 exp5 的 `legacy_metrics.Objective`。
- 优化器：AdamW；学习率 1e-3，预热 100 步后余弦降到 3e-5；权重衰减 1e-5；梯度裁剪 1；批大小 32。

### 5.2 预检（结果写进 `results/preflight/`，完成后停下交用户确认）

1. **参数生成覆盖范围**：框架（类型 0）× 设防等级 6–9 × 层数 2–14，逐一导出参数，确认新模拟器剪切型路径能运行，且 T1 与独立特征值计算一致（相对误差小于 1e-10）。
2. **积分步长**：14 层、最强试算激励，比较 0.00025 秒和 0.000125 秒两种步长的峰值和时程。差异可以忽略就沿用 0.00025 秒。
3. **降采样一致性**：同一算例按"地面加速度与响应同一滤波路径"处理，核对积分网格上"绝对 + 地面"等于对齐后位移的二阶差分；由于地面与响应走同一线性滤波，50 Hz 上同样成立。
4. **计算成本**：200 个混合层数算例，多进程，记录单例耗时和体积。预估约 1 秒/例；实测超过 3 倍时，先缩小规模并报告用户。
5. **KNET 清点和去重**：计算每条的哈希、实测峰值、有效长度；找出近重复记录并分组；尝试从原始文件名恢复台站或事件信息。恢复不了时，结论只能写"在没见过的记录上"。
6. **强度标定**：只用训练池前 50 条记录，按 Sa(T1) 对数均匀抽样，找出使损伤等级分布约为 40% / 30% / 30% 的区间。开发集和测试集记录不参与标定。

### 5.3 地震动划分

1. 按近重复分组合并，用种子 20261023 打乱后按组划分：训练池约 2,574 条，开发集 300 条，KNET 测试集 600 条。
2. 训练池再用同一种子打乱，排成固定顺序。"n 条训练记录"就是取前 n 条，所以小子集一定包含在大子集里。
3. 跨数据库测试：PEER 去掉 peer_1–10 及其近重复记录。
4. 同一条基础波的所有算例只能在一个集合里。
5. 划分清单存为 `configs/record_split.json` 并记录哈希，冻结后不改。

### 5.4 结构和强度抽样（每个算例独立抽，抽样种子写进配置）

1. 结构类型固定为 0（框架）；阻尼 5%；层高 3 m；楼面 1,000 m²，楼面质量 1,000 kg/m²。
2. 抽层数、设防等级，用参数导出程序得到基础材料（同一组合的导出结果缓存复用）。
3. 抽刚度系数：所有楼层第 1 列（刚度）和第 2 列（屈服力）都乘以它。
4. 计算 T1，以及 T2、T3 和首层屈服剪力系数（首层屈服力 / (总质量 × 9.80665)）。后三者只存进元数据，不作为模型输入。
5. 计算 Sa(T1)，按冻结区间抽目标 Sa(T1)，换算出缩放倍数，记录 PGA。

## 9. 自检（`run.py` 的 `smoke`，训练前和用最终权重各执行一次，不通过就停止）

- 条件编码、编码器、解码器都能收到梯度；设防等级类别向量也能收到梯度。
- 响应标签换成 NaN，输出完全不变；修改总高度，输出完全不变。

- 时程末尾追加 NaN 并标为无效，有效部分输出不变。
- 绝对加速度 = 相对加速度 + 符号 × 地面加速度，逐点成立。
- 楼层位置为 0、1.2 或 NaN 时拒绝；没训练过的设防等级拒绝。
- 损失实现与 exp5 原损失函数一致。
- 自检不改变权重；保存的权重重新加载后，输出完全一致。

## 10. 报告内容

每个运行、每个集合都报告：

- 顶层和每层的位移、加速度 MSE；
- 损伤等级大于 2 的子集；
- **最大层间位移角误差**（`common.drift_summary`；层间位移角无量纲）：
  - 全楼最大值的 MSE（主指标）；
  - RMSE；
  - 平均偏差 = 平均(预测 − 真值)，负数表示低估；
  - 相对偏差 = 平均((预测 − 真值)/真值)，作补充；
  - 按层数分组的逐层 MSE 和逐层偏差；
- 最大层间位移角和顶层峰值加速度的"预测/真值"（中位数、10% 分位数、90% 分位数），作补充；
- 损伤等级的低估、高估计数；
- 代表算例图（按事先规则选，不按预测好坏选）；
- 最差算例图（单独标注）。

汇总时，每个变体给出各种子的平均值和范围，并列出 exp5 原结果作为参照。第二阶段另外报告各基线，以及模型相对零响应基线的 MSE 下降比例。

其他测试集（已见地震动参照、跨数据库、只有结构没见过、两者都没见过）的排序相同，`exp5_decoder` 在每一项上都最好或并列最好。

**加速度误差按频段拆分**（`codes/spectral_check.py`，开发集目标居中的种子；表中为"预测能量 / 真实能量"）：

| 变体 | 2–5 Hz | 5–10 Hz | 10–15 Hz | 15–25 Hz |
|---|---:|---:|---:|---:|
| `exp5_decoder` | 0.85 | 0.24 | 0.02 | 0.05 |
| `ground_residual` | 0.87 | 0.51 | 1.90 | 2.18 |
| `local_snippet` | 0.83 | 0.45 | 2.20 | 2.19 |
| `local_snippet_absolute` | 0.78 | 0.23 | 0.02 | 0.06 |
| `cross_attention` | 0.77 | 0.46 | 0.15 | 1.14 |

**结论：**

1. **位移变差来自局部片段和交叉注意力，而且是欠拟合。** 加入片段后，训练集位移 MSE 从 1.2e-5 升到 2.0e-5；不输出相对加速度时升到 5.4e-5；交叉注意力升到 1.2e-4。训练集本身就拟合得更差，不是泛化问题。可能的原因是，原始片段数值未经归一化，直接加到 32 维楼层查询上，干扰了楼层信息。
2. **输出相对加速度（加上地面项）对总加速度 MSE 基本没有影响，但改变了误差在频率上的分布。**
   - 5–10 Hz 的预测能量从 24% 提高到 51%，相对误差从 0.74 降到 0.48；
   - 但在 10 Hz 以上，预测能量变成真实值的约 2 倍：地面运动的高频成分被原样加进来了，而真实楼层在高频上是衰减的，模型没有学会把它抵消；
   - 强非线性算例的加速度 MSE 因此变差（0.195 → 0.246）。
3. **地面项需要"按频率的增益"。** 相对加速度的写法，相当于对地面加速度在所有频率上乘以 1。如果改成可学习的、随频率、结构和楼层变化的传递函数 H(f)，就有可能保留 5–10 Hz 的改善，同时压掉 10 Hz 以上的多余能量。这一项作为 exp8 的候选。
4. 按事先规定的开发集规则，第二阶段的最终模型仍是 `exp5_decoder`。
